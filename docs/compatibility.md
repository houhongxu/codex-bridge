## CI 的含义

CI 在 Linux/macOS runner 上运行临时 WebSocket 服务、临时用户目录中的文件操作和文档检查，不安装真实桌面应用，不发模型请求。CI 通过代表代码回归检查通过，不能证明某个桌面版本的宠物 UI 可用。

## 手工验证清单

在个人可控的测试环境中，记录实际版本和每项结果：

- [ ] 从干净终端安装；已有别名冲突被清晰拒绝，`.zshrc` 修改有备份。
- [ ] 移动源码目录后，`cpet --version` 与 `cpet status` 仍可运行。
- [ ] 首次连接前退出已结束任务的桌面应用；重新打开后连接共享后台。
- [ ] 在测试项目中运行 `cx`，普通任务首次接入可以建立订阅。
- [ ] 同一任务继续提问，桌面不反复导航，宠物在合适状态下仍显示任务。
- [ ] 取消审批的决定按原样到达后台。
- [ ] 临时任务不会导致桌面打开或 `no rollout found` 错误。
- [ ] 桌面重启后，下次 CLI 提问可以恢复接入。
- [ ] `disable` 保留当前服务，`off` / `uninstall` 的停止影响符合文档。

请不要为了验证而中断正在进行的重要任务。提交兼容性报告时区分“测试通过”“未测试”和“失败”，不要根据功能列表代填结果。
