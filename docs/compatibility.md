## 回答排版验证（0.1.0-alpha.3，2026-09-17）

50 项隔离测试在本机 Python 3.9 和 3.14 通过。新增覆盖实时回复、开始/完成事件一致性、恢复/读取/历史分页、多问题及中文换行、原始数据不变、未知格式和引用保留。WebSocket 用例同时验证后台收到原始信封、CLI 收到可读文本、对应提问框仍收到关闭通知。

原版 CLI `0.155.0-alpha.2.6` 的隔离终端探针已确认：模拟桌面回答及 CLI 回答均显示为可读文本，隐藏原始信封，提问框正常关闭；后台捕获的提交仍为原始格式。事件时间戳按当前 CLI 生成的协议补齐，探针不向模型提交请求。

排版仅改变 CLI 收到的副本，不代表修改了后台历史。运行中的旧 `cx` 仍需退出后重新启动；退出适配会恢复原始显示。

## 空会话命名兼容（2026-09-20）

桌面包 `26.915.31029`（build `9771`）内置 CLI `0.155.0-alpha.9` 的隔离 App Server 探针仍可观察到：分页空会话命名只更新索引，历史文件尚不存在。官方 `thread/read(includeTurns=true)` 会请求持久化；对未索引的空任务，它可能在落盘后返回历史投影错误，因此转接器依据可读的 `session_meta` 判断是否可以继续命名。

未修复对照中，alpha.9 可以恢复仍加载的命名空会话，但命名后直接关闭隔离后台再冷恢复仍报 `no rollout found`，说明仅升级应用并不足够。修复后已验证空历史读取、同进程恢复和隔离后台重启后的冷恢复，未产生用户消息。

使用临时 `CODEX_HOME`、独立后台和不可用的本地测试模型地址验证，不使用用户凭据、不调用模型、不打开真实桌面。可显式运行真实后台回归：

```sh
CPET_TEST_CODEX=/path/to/codex .venv/bin/python -m unittest discover -s tests -p test_empty_thread_integration.py -v
```

默认 CI 跳过真实二进制探针，运行合成协议回归。桌面 GUI 手动点击验收、故障现场仍运行的旧 `0.155.0-alpha.2.6` 后台尚未验证；不为验证重启共享后台。应用包升级不会替换已运行的后台进程，新 CLI 与旧后台可能暂时混用。

公开 [官方 changelog](https://learn.chatgpt.com/docs/changelog) 在检查时最新桌面条目为 2026-09-11 的 `26.908`，主要涉及 Pets 快速聊天、Windows Appshots 和 UI 改进，未明确宣称修复空会话恢复。不能把公开条目的版本号视为本机包的逐构建兼容保证。

## CI 的含义

CI 在 Linux/macOS runner 上运行临时 WebSocket 服务、临时用户目录中的文件操作和文档检查，不安装真实桌面应用，不发模型请求。CI 通过代表代码回归检查通过，不能证明某个桌面版本的宠物 UI 可用。

空对话延迟接入依赖生命周期响应中的本地 `thread.path` 和 JSONL 首行 `session_meta`。该路径在内置 CLI `0.155.0-alpha.2.6` 生成的协议中标为不稳定字段；缺失路径或未知格式会跳过自动接入。回归测试使用临时文件与合成 WebSocket 消息，覆盖首条消息后延迟落盘、部分写入、超时重试、接入去重、连接清理，以及等待期间的消息和审批转发；修复后的真实桌面 GUI 端到端验收仍待完成。

## 手工验证清单

在个人可控的测试环境中，记录实际版本和每项结果：

- [ ] 从干净终端安装；已有别名冲突被清晰拒绝，`.zshrc` 修改有备份。
- [ ] 移动源码目录后，`cpet --version` 与 `cpet status` 仍可运行。
- [ ] 首次连接前退出已结束任务的桌面应用；重新打开后连接共享后台。
- [ ] 在测试项目中运行 `cx`，普通任务首次接入可以建立订阅。
- [ ] 新建空对话时桌面不提前导航、不反复报恢复失败；首条消息发送且历史生成后自动接入。
- [ ] 同一任务继续提问，桌面不反复导航，宠物在合适状态下仍显示任务。
- [ ] 取消审批的决定按原样到达后台。
- [ ] 恢复连接后产生两个新的异步问题：桌面回答第一个，CLI 关闭对应框；CLI 回答第二个，桌面显示相同答案。
- [ ] 空闲后从 CLI 回答尚未解决的实时问题，答案到达同一任务。
- [ ] 断连/提交失败明确提示，不静默自动重试；退出适配可恢复原始行为。
- [ ] 临时任务不会导致桌面打开或 `no rollout found` 错误。
- [ ] 桌面重启后，下次 CLI 提问可以恢复接入。
- [ ] `disable` 保留当前服务，`off` / `uninstall` 的停止影响符合文档。

请不要为了验证而中断正在进行的重要任务。提交兼容性报告时区分“测试通过”“未测试”和“失败”，不要根据功能列表代填结果。
