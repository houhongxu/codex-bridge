# cpet 0.1.0-alpha.3

异步问题回答后，CLI 现在将标准回复显示为“问题 / 你的回答”，不再直接展示同步标签和 JSON。实时消息与重新加载的历史记录均适用。

```text
问题：本次修改哪些页面？
你的回答：只修改列表和模板，其他页面保持不变。
```

只改变 CLI 的显示副本，问题和答案原文保留。后台保存及提交内容、桌面回复格式、问题编号匹配与真实审批保持不变。普通文本、引用示例、附件及未知格式原样传递。

## 升级与回退

在源码目录执行 `git pull --ff-only` 和 `./install.sh`，确认 `cpet --version` 为 `0.1.0-alpha.3`。结束当前工作后退出需要更新的旧 `cx`，再运行 `cx resume --all`。安装不重启共享后台或桌面；已经显示在终端滚动区的旧文本不会就地刷新。

`CPET_QUESTION_SYNC=0 cx resume --all` 可同时关闭问答适配和排版。完整回退可签出 `v0.1.0-alpha.2` 后重新安装并重开 `cx`。

## 验证范围

50 项隔离测试在本机 Python 3.9/3.14 通过，覆盖实时/历史排版、中文及多问题、后台原始消息保留、关闭通知、未知格式与退出适配。原版 CLI `0.155.0-alpha.2.6` 的隔离终端探针已确认两端回答显示为可读文本，关闭通知仍生效，后台提交保持原始格式。完整桌面 GUI 与真实模型的端到端流程仍未验收；查看 [兼容性记录](https://github.com/houhongxu/cpet/blob/v0.1.0-alpha.3/docs/compatibility.md)。
