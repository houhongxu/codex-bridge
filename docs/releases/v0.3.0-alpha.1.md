# 0.3.0-alpha.1（开发版本）

## Breaking change：cb → cx

项目继续名为 Codex Bridge；唯一入口改为小写 `cx`，源码入口为 `cx.py`。不保留 `cb` 兼容命令。管理命令和 CLI 命令改为 `cx status`、`cx resume --all`、`cx cli --help` 等。

从更新的源码执行 `./install.sh`，打开新终端，或执行 `unalias cb cx cpet 2>/dev/null; source ~/.zshrc`。安装器替换管理的别名块，清理指向旧运行副本的 `cb` / `codex-pet` 链接，更新下次登录命令。用户自定义的同名文件不会被删除；外部 `cx` 别名、函数或同名文件冲突时拒绝覆盖。

配置继续使用 `CB_PYTHON`、`CB_QUESTION_SYNC`。后台地址、launchd 标签、运行目录与会话数据不迁移，安装不重启正在工作的进程。结束当前工作后重新启动 CLI 才会加载更新。

## 桌面版 Codex 与终端

两个前端和共享后台使用桌面应用自带的 Codex CLI，无需独立 npm CLI。相同二进制只统一版本；共享 App Server 加上桌面任务订阅才共享运行中的会话、消息和任务事件。实时异步问答另由兼容层适配，历史未答问题仍需在桌面处理。

兼容桌面新旧 CLI 路径。完整说明见[README](../../README.md)和[实现原理](../architecture.md)。

## 回退

签出先前版本源码并重新安装，打开新终端。旧安装器不会移除新版 `~/.local/bin/cx`；回退后停止使用该入口。确认该链接仍指向新版运行副本后才手动移除。后台与会话数据保持原位。
