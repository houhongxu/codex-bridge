# cpet 0.1.0-alpha.2

修复“桌面已经回答异步问题，CLI 仍显示待回答”的兼容性问题。改动全部位于 cpet，不修改或重新编译官方 CLI，也不修改桌面应用。

## 使用变化

- 新启动的 `cx` 默认将实时异步问题显示为 CLI 标准提问框。
- 桌面提交答案后，关闭 CLI 中对应的问题；也可以直接在 CLI 回答，提交到同一任务。
- 真实审批保持原样；空答案不会变成默认同意。已知重复及迟到回答会被忽略，失败或超时不会自动重试。

## 升级

```sh
cd /path/to/cpet
git pull --ff-only
./install.sh
cpet --version
# 结束当前工作后退出旧 cx，再恢复任务：
cx resume --all
```

安装仍使用固定运行副本，移动源码不影响命令。本次安装不重启共享后台或桌面；运行中的旧 CLI 需要自行退出后重开。

## 已知限制与回退

仅适配连接后收到的新问题。恢复历史时保留问题正文，不重建旧提问框；历史未答问题请在桌面回答。标准提问框的 `Esc` 会中断当前任务。两端完全同时作答仍可能产生两条答案。

遇到 “cpet could not confirm this answer”，先查看桌面是否已收到，再决定是否重答。临时停用适配：

```sh
CPET_QUESTION_SYNC=0 cx resume --all
```

完整回退可签出 `v0.1.0-alpha.1` 后重新运行安装器，并重开旧 `cx`；无需停止共享后台来回退这次脚本改动。

## 验证范围

隔离测试覆盖两端回答、多个问题、任务与连接隔离、重复/迟到回答、提交失败/超时、历史分页、普通 RPC 和审批保留、独立安装。原版 CLI `0.154.0-alpha.6.2` 的真实终端 UI 已通过合成事件探针：模拟桌面回答关闭第一个问题，CLI 回答第二个问题，仅转发一次答案。

探针没有发真实模型请求；真实模型与桌面 GUI 点击的完整端到端验收、其他 CLI 版本仍未验证。详情见 [兼容性记录](https://github.com/houhongxu/cpet/blob/v0.1.0-alpha.2/docs/compatibility.md)。
