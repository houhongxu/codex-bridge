# cpet 0.1.0-alpha.1

首次公开预发布：让 macOS 上的 Codex CLI 普通任务接入桌面应用的原生宠物进度显示。

## 包含什么

- `cx` 自动准备共享 App Server 与每个 CLI 的本机转接器。
- 首次建立桌面订阅，后续提问复用；检测失效后按需重新接入。
- 过滤临时任务，避免误开没有持久化记录的会话。
- 独立运行目录和 Python 环境，移动或删除源码不影响已安装命令。
- 登录自启、诊断、回归测试，以及中英文使用说明。

## 安装与升级

按 [README](https://github.com/houhongxu/codex-bridge#快速开始) 安装。已有本机脚本用户也需要运行一次 `./install.sh`，将命令迁移到固定运行副本。结束当前一轮后退出旧 CLI，再用 `cx resume --all` 恢复。

## 验证与限制

自动化测试覆盖转发、审批保留、订阅复用与失效、临时任务过滤、安装隔离和源码删除。自动测试不调用真实模型，也不证明所有桌面版本均可显示宠物。

初始集成观察来自 macOS 上 `ChatGPT.app 26.908.70816` 和应用内 Codex CLI `0.154.0` 系列。首次订阅仍可能切换桌面页面；文件权限、代理、桌面专用工具及日志格式兼容性见 [兼容性说明](https://github.com/houhongxu/codex-bridge/blob/main/docs/compatibility.md)。
