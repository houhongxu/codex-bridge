# Codex Bridge 0.2.0-alpha.1（待发布）

本次是 breaking change：项目定位为 Codex CLI 与桌面端共享后台、会话和任务状态的桥接工具，宠物展示是其中一个桌面入口。

- 唯一入口为 `cb`；移除 `cx`、`cpet`、`codex-pet`，无兼容别名。
- `cb` / `cb resume <任务>` 启动和接续 CLI；`cb status` 等管理后台；`cb cli ...` 显式转发官方 CLI 参数。
- `cb --help`、`cb --version` 查询 Bridge；官方 CLI 帮助和版本使用 `cb cli --help`、`cb cli --version`。
- 配置变量改为 `CB_PYTHON`、`CB_QUESTION_SYNC`；旧变量不再读取。

升级时从新源码执行 `./install.sh`，然后打开新终端，或执行 `unalias cx cpet 2>/dev/null; source ~/.zshrc`。安装器更新管理的别名块，清理指向旧运行副本的命令链接，并更新下次登录使用的自启路径；发现用户自定义 `cb` 别名或同名文件时拒绝覆盖。

不移动现有会话、后台地址或运行目录，不重启现有 CLI、桌面或共享后台。旧 CLI 需结束当前工作后重新启动。GitHub 仓库为 `houhongxu/codex-bridge`；历史版本说明保留当时的命令名称。

验证范围以 PR 的测试记录及 [兼容性说明](../compatibility.md) 为准；本版本仍为实验性版本，不承诺所有桌面能力完全双向同步。

如需回退，使用先前版本源码重新安装，并打开新终端。旧安装器不会清理新版的 `~/.local/bin/cb`，回退后不要继续使用它；会话数据保持原位。
