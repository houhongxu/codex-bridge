# 路线图

这里列出方向，不承诺交付日期。优先根据可复现问题调整。

## 当前优先

- 收集不同 macOS、Python、桌面版本的真实兼容性结果。
- 提高订阅失败原因的可读性，减少依赖日志格式的脆弱点。
- 验证干净机器上的安装、更新、源码移动及卸载体验。
- 增加脱敏诊断输出，帮助用户报告问题。

## 后续评估

- 探索有官方支持、无需导航桌面的订阅方式。
- 可配置端口和应用路径，以及固定共享端口的鉴权方案。
- 英文命令输出与更多 shell 的安装入口。
- 更完整的桌面工具和 macOS 权限兼容性说明。

## 当前范围外

Windows/Linux 桌面集成、任意厂商 CLI 接入、公网远程服务器、多用户权限隔离、自定义宠物渲染与绕过桌面权限验证。
